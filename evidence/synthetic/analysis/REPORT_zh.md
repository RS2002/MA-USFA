## 原有结论与组件贡献

- **在每个正κ超过三个固定组合规则（all-32均值）**：`supported_by_test_means`；均值领先12/12项。只判定所声明均值排序是否保持，不作显著性或普适安全判断。
- **在每个正κ超过三个固定组合规则（Overlap均值）**：`partially_supported_by_test_means`；均值领先5/12项。只判定所声明均值排序是否保持，不作显著性或普适安全判断。
- **上层学习的增益**：`not_supported_by_test_means`；均值领先0/5项。跨五个κ的平均回报差为-0.440267；完整逐κ及逐种子差值见CSV。
- **跨token attention交换的增益**：`mixed_across_kappas`；均值领先1/5项。跨五个κ的平均回报差为-0.080730；完整逐κ及逐种子差值见CSV。
- **下层队友任务条件的增益**：`mixed_across_kappas`；均值领先3/5项。跨五个κ的平均回报差为+0.174264；完整逐κ及逐种子差值见CSV。
- **SF候选基础分数的增益**：`supported_at_all_tested_kappas`；均值领先5/5项。跨五个κ的平均回报差为+6.833966；完整逐κ及逐种子差值见CSV。
- **相同上层预算下优于共享任务条件DDQN**：`supported_at_all_tested_kappas`；均值领先5/5项。跨五个κ的平均回报差为+4.407060；完整逐κ及逐种子差值见CSV。
- **相同lower+upper transition总预算下优于共享任务条件DDQN**：`supported_at_all_tested_kappas`；均值领先5/5项。跨五个κ的平均回报差为+1.980093；完整逐κ及逐种子差值见CSV。
- **Distinct目标组相对primitive Independent的排序**：`mixed_or_independent_higher`；均值领先0/4项。保留组间差异，不能由all-32均值推断每个目标组均领先。
- **接近逐目标从头重训性能**：`not_evaluated_on_independent_test`。当前test没有逐test目标重训模型；旧validation的逐目标重训结果仅作原验证分析，不移作test参照。

这里的判断描述测试均值排序及其覆盖范围；三个训练种子的差异完整保留，不进行显著性检验，不自动调整方法、训练配方或检查点。

## 训练成本与比较含义

| 方法 | lower transitions | upper / shared transitions | 合计 | 验证机会 |

| MA-USFA (DDQN) | 81,920 | 81,920 | 163,840 | 32 |
| SF候选贪心（无上层学习） | 81,920 | 0 | 81,920 | 0 |
| 无跨token attention | 81,920 | 81,920 | 163,840 | 32 |
| 无SF | 0 | 81,920 | 81,920 | 32 |
| 下层无队友任务条件 | 81,920 | 81,920 | 163,840 | 32 |
| 共享DDQN（81,920） | 0 | 81,920 | 81,920 | 32 |
| 共享DDQN（163,840） | 0 | 163,840 | 163,840 | 64 |

成本列按一个κ、一个训练种子的模型开发成本记账。主方法、SF候选贪心和无attention变体复用同一个已训练下层；不能将表中重复计入的方法成本直接相加当作本轮新增训练量。源策略库提供先验，构造成本单列于方法说明，不隐藏进共享DDQN预算。

- **无上层学习**：同一冻结SF和源动作，直接按每个agent的候选分数选源；与使用精确SF、允许全部primitive动作的Independent不同。
- **无attention**：attention矩阵固定为单位阵，修正头只读取自己的value token；token仍包含队友任务权重，全局正权mixer保留，因此这里检验跨token交换。
- **下层无队友任务条件**：仅从下层输入删除队友任务权重；原reference采样过程和上层完整任务条件保留。
- **无SF**：去掉SF输入和加性基础分数，上层从零学习无界utility，避免人为将Q范围压到[-8,8]。
- **共享DDQN**：完整状态与双方任务权重输入一个13→64→64→25网络，可选择全部25个primitive联合动作；MA-USFA只能执行源策略提供的候选动作。两个预算为独立训练，163840预算不是81920模型的续训。较长预算同时有64次验证机会，短预算有32次。
